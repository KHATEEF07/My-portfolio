KHATEEF — NARUTO-INSPIRED DEVELOPER PORTFOLIO

HOW TO PREVIEW
1. Extract this ZIP folder.
2. Open index.html in Chrome, Edge or Firefox.
3. For best results, use VS Code + the Live Server extension and click “Go Live”.

HOW TO PUBLISH
1. Upload the contents of this folder to your GitHub repository (index.html must be in the repository root).
2. In GitHub, open Settings > Pages.
3. Choose Deploy from a branch, select main and /(root), then Save.

PERSONALIZE BEFORE PUBLISHING
- Replace assets/resume.pdf with your latest resume PDF. The resume button already points there.
- Verify the email address and profile links in index.html.
- Review project and internship descriptions for accuracy.

LIVE EFFECTS INCLUDED
- Animated drifting leaves and glowing chakra particles (canvas)
- Name glow, animated project art, rotating profile seal
- Scroll reveal and active-section navigation
- Pointer aura, mobile navigation and optional synthesized ambient drone
- Responsive layouts and reduced-motion accessibility support

NOTES
- The generated Konoha-inspired hero artwork is in assets/konoha-hero.png.
- The optional sound is synthesized by the browser and is not a Naruto soundtrack.
- This project uses plain HTML, CSS and JavaScript; no build step is required.
